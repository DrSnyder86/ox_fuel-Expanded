# ox_fuel Assets

Persistent electric charger and connector models for ox_fuel Expanded.

Keep this folder named `ox_fuel_assets`, start it before `ox_fuel`, and leave it running when restarting `ox_fuel`. Live unloading of the custom YTYP archetypes can crash a connected FiveM client.

Install this companion during a full server restart when migrating from an ox_fuel build that contained the electric `stream` folder. Once the companion owns the archetypes, `ox_fuel` can be restarted independently.
